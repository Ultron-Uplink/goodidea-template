## Start here
1. Read `AGENTS.md`, then `docs/product/PRD.md` and `STATUS.md`.
2. Take the first open, unassigned issue labelled `milestone:m0`.
3. Create `agent/<issue>-<ticket-short-name>`; keep the work to one small PR.
4. Run `pnpm install --frozen-lockfile`, then `pnpm verify`.
5. Open a PR with `Closes #N` and check output; the owner reviews and merges (L0).
